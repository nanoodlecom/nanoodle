Prompt to an editable SVG sticker

Get a logo, sticker or icon as a real vector file from one prompt.

A baby dragon sticker as a real SVG, 122 vector shapes and no embedded raster · 2026-10-30 · Reported saved run: $0.179. blackforestlabs/flux-3/klein/text-to-image · ideogram/vector

Show the Edit node with Ideogram Vector in convert mode. It takes any image and returns an SVG made of shapes, with no prompt needed, so it works on generated art and on your own drawings.

Saved result

FLUX.3 Klein paints a sticker of a baby dragon holding a paper lantern in a flat style on a white background. Ideogram Vector, in convert mode with a blank prompt, turns that image into an SVG with 122 vector shapes and no embedded raster, so you can zoom to 8× and the edges stay crisp, then edit the shapes in any vector tool. Flaws: the prompt asked for four flat colours, but FLUX added soft shading and a white sticker border, and the vectorizer kept them faithfully, so the SVG has about 25 fills and 5 gradients rather than a minimal palette. The sticker PNG was re-encoded to WebP for the gallery; the SVG is as returned. Inspired by @AllaAisling's Ideogram Vector post (https://x.com/AllaAisling/status/2113305041906061472). No media from that post is used. Every image was checked and is SFW (a cartoon dragon).

Make it yours

  1. Open the graph — save first if the canvas already has your work. Undo brings yours back.
  2. Change Sticker concept for your design and keep the flat-colour, plain-background wording, which vectorizes cleanly. Swap the image node for a 📷 Image input to vectorize your own sketch or logo.
  3. Check the editor estimate, then run with your NanoGPT key. FLUX.3 Klein 1024² $0.009 + Ideogram Vector convert $0.17 = $0.179 per run. Vectorizing your own image costs $0.17.
  4. Open the SVG and zoom in: the edges should stay sharp. Count the colours and gradients if you need a minimal palette, since shading in the raster becomes extra shapes.
