What this workflow is for

A reusable destination-plus-style illustration. The sample place lives only in the input, so a new destination should not inherit Taipei night-market scenery.

How to use it

  1. Open the graph with the button below. Save current work first — loading an example replaces the canvas (Undo restores it).
  2. Edit the inputs. Rewrite Place and pick a Vibe. GLM Flash writes the postcard prompt; Muse renders at 3:2.
  3. Inspect the result. Landmarks and local details should match the brief you typed. The reviewed sample is a coherent illustrated night market with a food-stall focal point — an illustration, not a documentary image or a print-ready layout with typeset copy.
  4. Typical cost. The reviewed run reported $0.01. The image step is listed at $0.01, plus a small text call. Prices and results vary.
