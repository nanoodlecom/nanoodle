Slice 3D · Fox walk cycle

Turn a rigged 3D character into a walking pixel sprite.

Twelve distinct frames of the Fox Walk clip from a fixed viewpoint. · 2026-11-21 · Reported saved run: $0.

The graph includes Fox, a textured GLB with three animation clips. Slice 3D samples the Walk clip at twelve evenly spaced poses. Sprite stack render plays those poses from a fixed camera. Both nodes run locally.

Connect 3D input model → Slice 3D model, then Slice 3D sheet → Sprite stack render sheet. The sheet output holds one horizontal slice sheet per pose in an animated PNG. The renderer’s image output is the first view and video is the animated MP4.

Saved result

The saved MP4 is one 0.708-second walk cycle. The head and tail stay in view while the legs change pose. The source model is by PixelMannen (CC0), with rigging and animation by tomkranis and glTF conversion by AsoboStudio and scurest (CC BY 4.0).

Make it yours

  1. Open the graph — save first if the canvas already has your work. Undo brings yours back.
  2. On Slice 3D, choose Run or Survey from the Animation clip menu to try Fox’s other animations. For a still, set Output to Still PNG · rest pose. Use 3D input to upload your own model, or wire the model output of a rigged 3D model node directly to Slice 3D.
  3. Click Run in the editor. This workflow runs on your device and needs no NanoGPT key.
  4. The Character preset uses 128-pixel tiles, 80 slices, source colors and outlines. This Fox example switches outlines off to keep the orange coat smooth. Turn them on and compare the legs and tail. For thin parts, try a pitch of 20–30° and layer spacing of 1. As pitch approaches 0°, you see the slices edge-on and gaps can appear. Enable Record turntable to orbit the stack as the character moves.
