What this workflow is for

Replace a busy background while keeping the product itself. Start here when you already have a photo (or a generated still) of the object.

How to use it

  1. Open the graph with the button below. Save current work first — loading an example replaces the canvas (Undo restores it).
  2. Edit the inputs. Upload your photo to Product photo and, if needed, tighten Edit request. Muse Edit uses that reference and the prompt.
  3. Inspect the result. Compare shape, color, materials, markings, and any visible text with the source. The sample turns a generated bottle into a catalog-style image on warm-white paper. Check real product markings before using a generated edit commercially.
  4. Typical cost. The reviewed run reported $0.01 ($0.01/image). Prices and results vary.
