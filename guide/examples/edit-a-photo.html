What it's for

Keep the object. Lose the clutter. Start here when you already have a shot — or a generated still — of the thing.

Remix it

  1. Open the graph. Save first — an example replaces the canvas. Undo brings yours back.
  2. Change the inputs that matter. Drop your photo on Product photo. Tighten Edit request if the default catalog brief is wrong. Muse Edit uses both.
  3. Look at what you got. Shape, color, materials, markings, visible text — compare them to the source. Check real product marks before you publish a generated edit.
  4. What it cost. The reviewed run reported $0.01 ($0.01/image). Prices and results vary.
