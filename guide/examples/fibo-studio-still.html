What this workflow is for

Describe a product and pick a light setup to get an editorial still of a fictional object. Use this when you do not have a real product photo yet.

How to use it

  1. Open the graph with the button below. Save current work first — loading an example replaces the canvas (Undo restores it).
  2. Edit the inputs. Rewrite Product (shape, materials, count) and pick a Light option. GLM Flash structures the brief; Bria FIBO renders at 1MP.
  3. Inspect the result. Product count, material, color, and the selected light should match the brief. No invented packaging, logos, or props. The sample is square and depicts a fictional bottle — it is not a photograph of merchandise. For an exact existing product, start with Clean a product photo instead.
  4. Typical cost. The reviewed run reported $0.04. The image step is listed at $0.04, plus a small text call. Prices and results vary.
