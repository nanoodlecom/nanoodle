A second camera on the same take

Add a second camera angle to a single AI video take, so you have something to cut to.

The same train, table, teapot and oranges, now filmed head-on from a low second camera · 2026-10-30 · Reported saved run: at least $0.5945. grok-imagine-video-1.5-lite · bytedance/seedream-v5.0-flash/edit · minimax/h3-lite

Show reference-to-video with a video reference. The clip pins the action and the look, and an edited still pins the new camera position, so H3 Lite re-films the same action from there.

Saved result

Grok Imagine 1.5 Lite films 5 seconds of a red-and-black toy steam train crossing a wooden trestle on a sunlit kitchen table, next to a blue teapot and a bowl of oranges. Frames pulls the still at 2.5 s, and Seedream 5.0 Flash Edit redraws it from a low front angle on the track. MiniMax H3 Lite gets the original clip as a video reference and that still as an image reference and re-films the same run head-on, so you get a second camera on a shot that only had one. Combine cuts A then C. Flaws: the redraw is plausible rather than 3D-correct, so the teapot moves from behind the bridge to beside the track, and near the lens the trestle turns into a flat curved track. Grok drew three carriages, not two. The saved run also made an unused overhead still ($0.027), which is not in this graph, and its Combine step dropped audio after 6.8 s, so the cut is not shipped here; the two camera clips are. The clips were re-encoded for the gallery. Inspired by @jerrod_lew's multi-angle workflow (https://x.com/jerrod_lew/status/2112889004928692268). No media from that post is used. Every still and sampled frame was checked and is SFW (a toy train, no people).

Make it yours

  1. Open the graph — save first if the canvas already has your work. Undo brings yours back.
  2. Change Shot for your take, or wire a 📹 Video input in place of Camera A. Describe the new camera in Angle C · low front, and duplicate the Frames → Edit → Video edit branch with another angle text for more cameras. Re-film brief C tells the video model to keep the action and change only the camera.
  3. Check the editor estimate, then run with your NanoGPT key. Grok Imagine 1.5 Lite $0.10 + Seedream 5.0 Flash Edit $0.027 + H3 Lite reference-to-video at 480p, which billed $0.4675. With your own clip, each extra angle costs about $0.49.
  4. Compare A and C at the same moments: the props, colours and light should match. Check the set geometry, since the new angle is a redraw, and watch the cut at the end of A for audio.

The Seedream edit node now asks for the 2k size the current catalog lists; the saved run used the older 16:9 setting.
