Idea to concept art to 3D model

One object idea → an LLM concept description → a clean concept render → a textured GLB you can orbit.

Orbited in the editor · 2026-10-12 · Reported saved run: $0.21007. z-ai/glm-5.3-flash · meta/muse-image/text-to-image · wavespeed-ai/trellis-2/image-to-3d

Image-to-3D models work best from one clear object on a plain background. An LLM writes the object's parts, materials, and colors; Join adds fixed 3D-ready render rules; Muse paints the concept; TRELLIS.2 turns that single image into a textured GLB. Inspired by <a href="https://x.com/patchmonkeydev/status/2109453424643428622">@patchmonkeydev on X</a> (prompt → concept → multi-view → 3D in ComfyUI); only the idea is used.

Saved result

GLM 5.3 Flash turns a one-line object idea into a concept description: a teal capsule-shaped toy submarine with a cream belly band, a brass periscope, three cream-rimmed portholes, a brass wind-up key, and a striped tail cone with a three-blade propeller. Join adds fixed render rules (one whole object, three-quarter view, plain light-gray background, no props), and Muse paints the concept. TRELLIS.2 (1024 geometry, 1024 textures, about 80k faces) turns that single picture into a 3.6 MB textured GLB. Orbiting it in nanoodle's 3D viewer shows a complete toy from every side, including a far side and back that the picture never showed: portholes on both flanks, the striped tail, the propeller blades, the key, and the periscope. Flaws: the viewer renders it flatter and less glossy than the concept, the thin key and propeller blades go soft at some angles, and the cream band on the far side is a plainer flat strip. Inspired by @patchmonkeydev's prompt → concept → multi-view → 3D ComfyUI pipeline on X; no media from that post is used.

Make it yours

  1. Open the graph — save first if the canvas already has your work. Undo brings yours back.
  2. Rewrite Object idea with one solid object (family-friendly). Keep the render rules if you want clean 3D: one whole object, plain background, no props. To trade price for detail, change the 3D model node's geometry resolution (512 / 1024 / 1536) or swap in Tripo 2.5 or Hunyuan. Running the graph makes one cheap text call, one image call, and one paid 3D call.
  3. Check the editor estimate, then run with your NanoGPT key. The saved sample reported about $0.21: TRELLIS.2 at $0.20 (1024 geometry), Muse text-to-image $0.01, and under $0.0001 for one GLM 5.3 Flash call. A concept-only test before the full run added about $0.01. Prices and results vary.
  4. Open the workflow and drag the 3D node to orbit the saved GLB. Check the sides the concept never showed: in the saved run the far side has portholes and a plainer cream strip, and the thin key and propeller blades go soft at some angles. The viewer shows flatter shading than the concept render.

The editor workflow also points the 3D node at the saved GLB as its sample, so you can orbit the result before running; ▶ Run replaces it. Everything else matches the sampled graph.
