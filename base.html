AI workflows for agents, paid in USDC on Base

Build a multi-model workflow visually. Hand it to an agent as one tool. The agent pays per call — no account, no API key of its own.

Status: in preparation — Base payments are not live yet

nanoodle is a node playground for AI: connect text, image, video, audio and 3D models into one workflow in the browser, then expose that workflow to agents as a single typed MCP tool through the hosted server at mcp.nanoodle.com. Instead of a subscription or a prepaid balance, the calling agent pays for each run as it goes.

Base is the next payment rail for those calls. The design follows the x402 protocol: the server answers a paid tool call with an HTTP 402 quote, the agent pays in USDC on Base, the workflow runs, and the agent gets its result with a receipt. Pricing is quoted per run before payment, from the models the workflow actually uses.

What is live today

  • The workflow editor — build and run workflows in your browser, free to open.
  • The hosted MCP server — agents already pay per call there in Nano, and in NEAR or USDC on NEAR through the NEAR front door.
  • The Base x402 adapter itself — built against the official x402 SDKs and qualified offline with adversarial payment tests (replay, expiry, cross-network races, settlement uncertainty).

What is not live yet — plainly

  • No live Base payments. The adapter stays inactive until the shared payment-authority service behind it ships; nothing on this page can take your USDC today.
  • No marketplace listing yet. nanoodle is not listed in Coinbase's x402 Bazaar or on Agentic.Market. Bazaar indexing follows a first real settlement, so a listing can only come after live payments open — anyone claiming otherwise is ahead of the facts.
  • No launch date. This page will drop the “in preparation” label when the first Base settlement has actually cleared, not before.

Can my agent pay with Base USDC right now?

Not yet. Today the hosted MCP server takes Nano, NEAR and USDC on NEAR. Base USDC over x402 opens when the payment-authority service ships and a first settlement clears — the same workflow your agent runs on the live rails will then accept Base payment unchanged.
